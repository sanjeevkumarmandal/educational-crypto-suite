# Open-Source Educational Cryptography & Steganography Sandbox

An interactive web application built with Streamlit designed to demystify complex cryptographic procedures, data integrity verification hashes, and pixel-level LSB data hiding methods.

## 🌟 Visual Features
- **Live SHA-256 Hashing:** Observe changes to cryptographic digital fingerprints in real time.
- **Symmetric Cipher Sandbox:** Interact with a bitwise symmetric key transformation loop.
- **Visual Image Steganography:** Upload standard carrier images to securely hide text payloads into individual pixel structures.
